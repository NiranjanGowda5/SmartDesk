# Role workflows

| Task | Employee | Support engineer | Administrator |
|---|---|---|---|
| Join SmartDesk | Register an employee account | Register, then receive the engineer role from an administrator | Use the seeded local administrator or receive the role from an administrator |
| Ticket visibility | Tickets opened by the employee | Tickets currently assigned to the engineer | All tickets |
| Open a request | Submit a title, description, category and priority | | |
| Add comments and inspect history | Own tickets | Assigned tickets | All tickets |
| Assign work | | | Select an active engineer or reassign an existing ticket |
| Advance work | Confirm resolution and close the request | Start investigation, pause, resume, or resolve with a note | Review the recorded changes |
| Directory and catalog | | | Change roles and active status, add or rename categories and priorities |
| Download report | | | Export the ticket register as CSV |

## Walk through a request

1. Sign in as an employee. Open a ticket with the affected service in the title and observed symptoms in the description.
2. Sign in as an administrator. Find the new ticket and assign an engineer.
3. As that engineer, start work and send a comment. For a dependency on employee input, mark the request pending, then resume it when the answer arrives.
4. Enter a resolution note and mark the ticket resolved. The employee can review the note in history and confirm closure.
5. Download the administrator CSV and locate the same ticket ID, owner, engineer and final status.

## Account lifecycle

Administrator access is required to manage the directory. Accounts can be deactivated, retaining the authorship of existing tickets, comments and history. An engineer's outstanding tickets must be reassigned before removing their engineer access. Account changes take effect on subsequent authenticated requests.
